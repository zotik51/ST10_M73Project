# Впрыск и зажигание: выходы, фаза, расписание

Продолжение [sync.md](sync.md). Разбор по `out/ST10.asm`, на железе не проверялось.

## 1. Выходы

| Что | Пины | Таймер | Как управляется |
|---|---|---|---|
| Катушки 1–4 | P2.0–P2.3 | CC0–CC3, compare по T0 | Пин переключается по совпадению (`CCMx` mode 5). Начало накопления и искра ставятся из расписания `E29E` (`sub_019A28` @ `0x019BCE`) |
| Форсунки 1–4 | **P8.2–P8.5** | **CC18–CC21**, compare по T0 | Открытие — сразу программно (`BCLR P8.x`). Закрытие — в ISR по совпадению `CCx = T0 + длительность` (`0x022B1E…0x022B48`, `BSET P8.x`) |

Функции управления форсунками:
- `sub_0228B4` — **синхронный впрыск** на цилиндр `E027`. Маска форсунок берётся из конфигурации `0x60710[E027 + 8·попарный]`.
- `sub_022978` — асинхронная добавка на все закрытые форсунки (обогащение при ускорении).
- `sub_022A24` — все 4 форсунки одновременно (пусковая подача).
- `FD18.8…11` — запрет отдельных форсунок (диагностика или отключение).

## 2. Конфигурационный блок `0x60700` (страница `0x18`)

Это не калибровки из .map, а отдельная область рядом с идентификацией:

```
0x60700: 01 02 04 08 00 00 00 00   01 02 04 08 10 20 40 80   битовые маски
0x60710: 01 04 08 02 00 00 00 00   09 06 09 06 00 00 00 00   форсунки по слотам: [последовательный] [попарный]
0x60720: 00D8 0240 03A8 0510 FFFF FFFF FFFF FFFF            ВМТ слотов, единица 0.5°
0x60730: 01 04 08 02 00 00 00 00   09 06 09 06 00 00 00 00   катушки по слотам: [индивидуальные] [попарные]
```

- **Слот** — это сегмент цикла по 30 позиций (180°), по порядку работы.
- Маски `01 04 08 02` означают порядок работы **1‑3‑4‑2**: слот 0 → цил. 1, слот 1 → цил. 3 и т. д.
- `09 06` — попарный режим: катушки и форсунки 1+4, 2+3.
- Углы ВМТ слотов: 216, 576, 936, 1296 → 108°, 288°, 468°, 648° от зуба 0. Шаг 180°.
- **Места под 8 слотов уже зарезервированы** (по 8 байт или 8 слов на таблицу), но код обходит только 4 (см. §5).

## 3. Фаза впрыска

1. `sub_022798` (периодическая задача):
   - фаза из таблицы «Фаза впрыска по наполнению» `0x764D3[E044]` или альтернативной `0x79494[E05D]`, выбор по биту 1 байта `0x7604D`;
   - единица — позиция 6°, со знаком;
   - **+19** (смещение ВМТ), по модулю **120** → `E02D`;
   - `/30` → `E023` (слот), `%30` → `E022` (позиция в слоте).
2. `sub_0227DE` (на каждом событии цилиндра, из `sub_019A28`):
   - поправка задержки по оборотам `0x7605E × E03A`;
   - в режиме «Фаза завершения впрыска» (бит 2 `0x7604D`) вычитается длительность впрыска, переведённая в позиции (`длит × период_зуба / 6`, не больше 120);
   - результат `E1A1`, к нему `E02D` подтягивается не быстрее **±1 позиции за событие**;
   - пересчёт `E022/E023`, модули **120** и **30** зашиты.
3. Когда в `sub_019A28` позиция в слоте `E013 == E022`:
   - вычисляется цилиндр `E027 = (слот − E023) mod 4`;
   - поднимается программное прерывание **CC12**, оно вызывает `sub_019D2A`.
4. `sub_019D2A` → … → расчёт длительности (`0x01A0F0`):
   - статическая производительность форсунки `0x76056`;
   - добавка в попарном режиме `0x760D9`;
   - минимальное время `0x75FA8`;
   - результат `0x8044`, перевод в тики T0: `×16/12`;
   - затем `CALLS sub_0228B4` — форсунки открываются сразу, в момент события.

Итого: впрыск начинается **на зубе**, с точностью до позиции 6°, без доли зуба. Длительность отсчитывается по таймеру.

## 4. Угол зажигания: `sub_022324`

Для каждого из **4 слотов** (`E27E…E28D`, по 4 байта):

```
угол = ВМТ_слота[0x60720]                     (0.5°)
     − УОЗ (sub_01BC58 по E2F2[слот] …)
     − коррекция УОЗ по цилиндрам 0x75FD0[слот]   (или 0x75FDA при отказе ДФ)
зуб  = угол / 12,  доля = угол % 12              (позиция 6° и шаг 0.5°)
накопление: время накопления 0x78B00(напряжение, обороты) → в позиции → зуб/доля раньше искры
запись: {зуб_накопления, доля, зуб_искры, доля}, доля переводится в байт по таблице 0x1FFDE
```

- На зубе 5 каждого слота строка копируется в рабочий буфер `E29E`.
- На каждом зубе `sub_019A28` ищет в `E29E` совпадение с текущей позицией `E014` и ставит compare: `время_зуба + (доля/128)·период`.
- Доля 128…245 — это **от 1 до 1.91 периода**: событие ставится на один зуб раньше, а точное время добирается таймером.
- Маска катушек слота берётся из `0x60730`.

Вторая искра: задержка `0x75FCF`, отключается выше оборотов `0x75FCE`. Она реализована в ISR катушек повторным переключением через `E3B0`.

## 5. Что зашито под 4 цилиндра

К таблице в [sync.md §4](sync.md#4-что-зашито-константами) добавляются:

| Адрес | Что |
|---|---|
| `0x0224B6` | `CMP R15,#0xE28E`: в расписании ровно **4 слота** |
| `0x0228A4`, `0x0227C6` | `/30`: позиция → слот для впрыска |
| `0x0227A8…0x0227B6`, `0x0227F4…0x02280A`, `0x022854` | `+120`, `−120`, `+19` |
| `0x0224A0` | `+120`: перенос зуба накопления |
| `0x01A132…0x01A13A` | `×16/12`: перевод длительности в тики T0 (зависит от тактирования T0) |
| `0x0228D0…0x02296E` | 4 форсунки, CC18–CC21 и P8.2–P8.5 |
| `0x019C08…0x019D26` | 4 катушки, CC0–CC3 и P2.0–P2.3 |
| буферы `E27E`, `E29E`, `E2F2`, `0x75FD0` | размер под 4 слота |

## 6. Что это значит для доработки

- **Порядок работы, попарный режим и углы ВМТ уже вынесены в конфигурацию** (`0x60700–0x6073F`). Для другого 4‑цилиндрового мотора (другой порядок работы, другое смещение ВМТ относительно пропуска) достаточно поменять этот блок. Код трогать не нужно.
- **Другой диск** при подходе «виртуальная сетка 6°» ([sync.md §5](sync.md#5-как-добавить-другие-диски-и-другое-число-цилиндров)) не затрагивает ни впрыск, ни зажигание: они работают в позициях сетки и в долях периода зуба. Нужно только, чтобы новый ISR выдавал правильные `E00E`/`E010` для виртуальных зубьев.
- **Другое число цилиндров** — правка по всей цепочке:
  - слот из 30 позиций становится 120/N;
  - цикл на 4 слота становится циклом на N;
  - нужны дополнительные выходы.
  
  Ресурсы МК:
  - CC17 занят (обработчик через `E146`);
  - **CC22–CC25 заняты под настраиваемые доп. выходы**: обработчики `E276–E27C` назначаются при старте из таблицы `0x62150` по маске `0x75542`, `sub_023316`. Это ШИМ и реле из меню «Доп. функции»;
  - свободными выглядят CC16, CC26, CC27 и P8.0/P8.1/P8.6/P8.7: их векторы не используются. Что из этого разведено на силовые драйверы платы, нужно смотреть по схеме блока. Для 3 цилиндров ресурсов хватает: слот 40 позиций, 3 из 4 каналов.
